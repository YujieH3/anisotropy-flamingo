# Cosmic anisotropy analysis with galaxy clusters

[![arXiv](https://img.shields.io/badge/arXiv-2504.01745-b31b1b.svg)](https://arxiv.org/abs/2504.01745)

This repo is a collection of the scripts used to analyse cosmic anisotropy using
galaxy clusters. It was originally applied to simulation data but can be
extended to real galaxy cluster catalogues. In fact we are extending the code to
real data. You can find the branch named 2504.01745, the archived version of
this repo that made the calculation used in [He et al.
2025](https://arxiv.org/abs/2504.01745).
